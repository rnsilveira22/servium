# Proposta de ADR — <título>

> Proposta de `servium-senior` (ou outro agente com justificativa). **Nenhum agente aceita o próprio ADR.** Formato e ciclo de vida definidos em [`docs/decisions/README.md`](../../decisions/README.md).

## Arquivo destino

`docs/decisions/ADR-<XXX>-<titulo>.md` — numeração sequencial, sem reuso.

## Estrutura obrigatória (conforme convenção do repositório)

```markdown
# ADR-XXX — Título

## Status
Proposed

## Context

## Decision

## Alternatives Considered

## Consequences

## Risks
```

## Checklist antes de propor

- [ ] Problema arquitetural real documentado (não preferência pessoal)
- [ ] Alternativas consideradas com trade-offs explícitos
- [ ] Aderência aos drivers em `docs/architecture/ARCHITECTURE_DRIVERS.md`
- [ ] Impacto em ADRs existentes verificado (nenhum conflito silencioso; se houver, indicar `Superseded`)
- [ ] Status inicial `Proposed` — decisão humana necessária para `Accepted`
