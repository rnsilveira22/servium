# Template de História (uso local)

> Fonte única do formato obrigatório: [`.github/ISSUE_TEMPLATE/story.md`](../../../.github/ISSUE_TEMPLATE/story.md).
> O PO deve criar histórias como GitHub Issues usando esse template — não manter backlog paralelo.

Regras complementares:

1. Título: `[SRV] <título curto>`; o número da Issue é o ID canônico (`SRV-<n>`).
2. Critérios de aceite em Given/When/Then, verificáveis por teste.
3. `Definition of Ready` completo antes de mover para `READY`.
4. Labels obrigatórias: `type:story` + prioridade (`priority:p0..p3`) + épico quando existir.
